# Descomplicando as finanças ;)

## 📒 Descrição
O projeto é desconplicar finanças, dismistificando as diversas formas de investimento, e para começar, o começo, aprendendo sobre poupança.

## 🤖 Tecnologias Utilizadas
Foram utilizadas as seguintes ferramentas de IA:
.ChatGPT
.Elevenlabs

Com o texto pronto, colei o texto no ElevenLabs e sintetizamos a voz.
